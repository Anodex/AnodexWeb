A few things to know.

Do I need a cloud account?+

No account is needed for the core desktop experience. Download a local model in Anodex, or add an existing GGUF file. Cloud providers are optional and use your own credentials.

Can Mobile work away from home?+

Yes, when your phone can reach your running desktop through a private VPN or a secure remote route you configure. The desktop and phone connect directly; Anodex does not provide a content relay.

Does my desktop need to stay on?+

Yes. Your desktop runs local models and tools and connects to any cloud provider you choose. Anodex must remain open and reachable for Mobile to use them. Scheduled desktop tasks also run while the app is open.

Where can I see what it looks like?+

Download the current desktop or Android build to explore the interface. The GitHub release notes describe what changed in each version.
